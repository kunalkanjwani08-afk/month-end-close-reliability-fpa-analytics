HOW TO RUN THE NOVABRIDGE PROJECT  (Windows / VS Code terminal; Linux/macOS commands in brackets)

Everything named below is in this repository. Large data files are stored compressed or are regenerated, see step 0.

0. DATA
   a) Raw data - decompress once (lossless; the result is byte-identical to the original extract):
        Windows (needs only Python):
          python -c "import gzip,shutil;shutil.copyfileobj(gzip.open('data/raw/fpa_monthly_close_raw_messy.csv.gz','rb'),open('data/raw/fpa_monthly_close_raw_messy.csv','wb'))"
        Linux / macOS / Git Bash:   gunzip -k data/raw/fpa_monthly_close_raw_messy.csv.gz
      Expected SHA-256 of the decompressed file:
        a0e6eddde25280aa27a60c5955743d3243b14138d876eedac0547e24a1cc6fff
      Check it:  python -c "import hashlib,sys;print(hashlib.sha256(open(sys.argv[1],'rb').read()).hexdigest())" data/raw/fpa_monthly_close_raw_messy.csv

   b) Cleaned data - the repository publishes the cleaned dataset as an Excel workbook:
        data/processed/fpa_monthly_close_cleaned.xlsx      (Cleaned_Data sheet: 152,682 rows x 77 columns, plus audit sheets)
      The SQL analysis needs the full 192-column CSV version of the same cleaned data (eligibility flags, scale adjustments).
      The CSV is not stored in the repository; regenerate it from the raw file with the cleaning script (about 4-5 minutes):
          python src/clean_fpa_monthly_close.py --output-dir data/processed
      Its SHA-256 must be:
        c184b677bacc6f23086e3b5eedd71836643cb75064e428a1ebfee4c075fa9b47
      (The same run rewrites the cleaned workbook, QC_Report.txt and qc_summary.json. The cleaned workbook content is identical;
       only its generation timestamp and input path change.)
      Without --output-dir the script writes to <your Downloads>\fpa_monthly_close_cleaned\, which the pipeline does not read.

1. ENVIRONMENT (Python 3.11 or newer)
     python -m venv .venv
     .venv\Scripts\activate            [source .venv/bin/activate]
     pip install -r requirements.txt

2. SQL ANALYSIS - build, validate and export (about 20-30 seconds)
     python src\sql_analysis_pipeline.py
   Exit code 0 = all 55+24+86+124 checks passed. Results: build\sql_results\*.csv + MANIFEST.json, database build\fpa_analysis.duckdb
   (both git-ignored; they are rebuilt on demand).
   Exit code 1 = missing/invalid input.  Exit code 2 = integrity/validation failure.
   On failure nothing accepted is overwritten; diagnostics go to build\sql_results_failed_run\ and build\fpa_analysis.duckdb.failed.

3. ANALYSIS DOCUMENTS - regenerate from the validated database
     python src\analysis_report_builder.py
   Writes docs\FINANCIAL_ANALYSIS_REPORT.md and docs\INSIGHT_REGISTER.md.

4. TESTS (about 80 seconds with the cleaned CSV, 2 seconds without)
     python -m pytest tests -q --ignore=tests\test_excel_workbook.py
   Without the cleaned CSV only the fixture tests run and the run is reported INCOMPLETE (non-zero exit).
   The Excel tests are run in step 5 because they compare the database hash recorded in the workbook; the DuckDB file is not
   byte-identical between rebuilds (its content is).

5. EXCEL WORKBOOK (a few seconds; needs the database from step 2 and the documents from step 3)
     python src\excel_workbook_builder.py
     python -m pytest tests\test_excel_workbook.py -q
     python src\excel_workbook_builder.py --qa-report
   Output: excel\fpa_month_end_close_analysis.xlsx (plus MANIFEST.json and EXCEL_QA_REPORT.md, git-ignored).
   LibreOffice (soffice) is needed for 2 tests; without it they are skipped and the run is reported INCOMPLETE.
   The workbook has not been opened in Microsoft Excel.

6. DASHBOARD
     python src\dashboard_builder.py
   Rebuilds dashboard\fpa_financial_analytics_dashboard.html. It needs the raw CSV (step 0a), the cleaned CSV (step 0b) and the
   workbook manifest (step 5) only to record their hashes in the page. Open the HTML in a browser: no server, no network.
   Optional browser tests (need Playwright + Chromium):  python tests\dashboard_browser_qa.py

Nothing here commits, pushes or publishes anything. Built and tested on Linux; not yet run on Windows.
